## Super Mona Kart (`super_mona_kart/`)

The badge mascots' Grand Prix: Mona (Flappy), Cluck (Plucky Cluck), Sciuri
(Snarky Sciuridae) and Buzz (Bee Amazed) race on four tracks in Mode 7, with
drifting, items, a Grand Prix with a podium, a time trial against your ghost,
and party races between badges over Wi-Fi. The case lights count down the
start, glow with your drift charge and flash when you boost or get hit.

Why it is built the way it is: [`DESIGN.md`](DESIGN.md).

### Controls

| Action | Touch face | Physical switches |
| --- | --- | --- |
| Steer | D-pad LEFT / RIGHT | Left / Right |
| Drift (hold, steer, release for a boost) | BACK | Up |
| Use item | SELECT | Select |
| Brake / reverse | D-pad DOWN | Down |
| Pause | MENU | hold Up + Down |
| Back in menus | BACK | Left (lists), Up (racer and track pickers) |

The kart accelerates by itself. HOME returns to the launcher.

### Modes

- **Grand Prix**: the Octo Cup, four races, points 10 / 7 / 5 / 3, a podium.
  Win on Normal to unlock Hard.
- **Quick Race**: one track against three computer karts.
- **Time Trial**: no items, three Commit Boosts, your best run saved as a ghost.
- **Party**: two to four badges on the same Wi-Fi; computer karts fill the rest.
  Set `WIFI_SSID` and `WIFI_PASSWORD` in the badge's `secrets.py`. A phone
  hotspot is the safest network; conference Wi-Fi often blocks badges talking
  to each other.

### A simulator that matches the firmware

The badge runs a derivative of `pimoroni/tufty2350`, which pins PicoVector
v3.1.0. The stock simulators do not match it, so we use a branch of
`pimoroni/badgeware-simulator` that links PicoVector v3.1.0 and boots the
firmware's own `badgeware` runtime, with GitHub's 2026 inputs emulated
(`pv3-runtime`, in `~/badgeware-simulator`). Unmodified 2026 apps run in it.

Build it once (macOS):

```sh
cd ~/badgeware-simulator          # branch pv3-runtime
git submodule update --init
(cd lib/micropython && git submodule update --init lib/micropython-lib lib/mbedtls)
export SDKROOT="$(xcrun --sdk macosx --show-sdk-path)"
cmake -S micropython -B build-pv3 && cmake --build build-pv3 -j8
cmake -S micropython -B build-pv3-headless -DHEADLESS=TRUE && cmake --build build-pv3-headless -j8
```

Play in a window:

```sh
python3 Team2/badgesim.py Team2/super_mona_kart --play --state ~/.smk-state
```

| Key | Badge |
| --- | --- |
| Arrow keys (or WASD) | D-pad / Up, Down, Left, Right switches |
| Space, Enter or X | SELECT |
| Backspace or Z | BACK (touch pad) |
| M or Tab | MENU (touch pad) |
| H | HOME (back to the launcher; closes the window) |

The four corners of the window glow with the case lights. P saves a
screenshot.

Scripted headless runs (`--press START-END:ACTION`, frames at 60 per second)
and two badges racing on one machine:

```sh
python3 Team2/badgesim.py Team2/super_mona_kart --frames 600 \
    --press 30-32:SELECT --shots 100,599 --out /tmp/shots
python3 Team2/badgesim.py Team2/super_mona_kart --play --port-offset 0 &
python3 Team2/badgesim.py Team2/super_mona_kart --play --port-offset 1 &
```

The simulator cannot prove frame rate, touch feel, the IMU, real Wi-Fi or
memory on the RP2350. Check those on a badge (Settings > Show frame rate).
